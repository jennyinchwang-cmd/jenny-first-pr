# สรุปสถานะ: ศาสตร์จีนที่เราศึกษา + ทำไว้ + ทำต่อได้ (Number Luck)
*รวบยอด 15 ก.ค. 2026 — ตามคำสั่งพี่เจน "สรุปว่าศึกษาจีนไว้ยังไง เอามาทำอะไรได้บ้าง"*

---

## 1) เราศึกษามาอย่างไร
- **วิจัยเชิงลึก 1 รอบ** (14 ก.ค. 2026, deep-research 105 agents, ตรวจไขว้ 3 ผู้ตรวจ) — รายงานเต็มที่ `auspicious-timing-cn-mm.md`
- ระดับความเชื่อมั่น: **สูง** สำหรับกลไกหลักและไลบรารี (ตรวจซอร์สโค้ด + รันจริงเทียบ almanac อิสระ)

## 2) ความรู้จีนที่ "ยืนยันแล้ว" (เขียนโค้ดได้จริง)
| หัวข้อ | คืออะไร | ใช้ทำอะไรได้ |
|---|---|---|
| **กานจือ 干支** | วัฏจักร 60 (ปี/เดือน/วัน/ชั่วโมง) คำนวณจากวันที่ deterministic | ฐานของทุกอย่าง + ดูธาตุ 五行 |
| **ปีนักษัตร 生肖** | 12 นักษัตร (ตัดขอบปีจีนจริง ไม่ใช่ 1 ม.ค.) | รู้ปีเกิดลูกค้า → ทำดวงเฉพาะบุคคล |
| **การชง 沖** | วันที่นักษัตรชนปีเกิดผู้ใช้ = วันร้ายเฉพาะคน | "วันนี้ชงคุณ" — จุดขายเฉพาะบุคคล (เหมือนวันเกิด 8 วันพม่า) |
| **宜/忌** | รายวัน ควรทำ/ห้ามทำอะไร (แต่งงาน/เปิดร้าน/ย้ายบ้าน...) | หัวใจของ "หาฤกษ์กิจการ" |
| **12 ผู้คุมวัน 建除** | 建除滿平定執破危成收開閉 หมุนรายวัน | วัน 開/成 เริ่มสิ่งใหม่ดี · วัน 破 ห้ามการใหญ่ |
| **หวงเต้า/เฮยเต้า 黃道/黑道** | วันเทวดาดี/ร้าย + ระดับ 吉/凶 | บวก/ลบคะแนนรายวัน |
| **28 นักษัตร 星宿** | ดาวประจำวัน + คำตัดสิน 吉/凶 | เสริมความละเอียด |
| **ทิศเทพเงิน 財神** | ทิศมงคลการเงินรายวัน | "วันนี้หันหน้าทิศไหนรับทรัพย์" |
| **ฤกษ์รายชั่วโมง 時辰** | 12 ยาม ดี/ร้าย | "เปิดร้านกี่โมงดี" |

## 3) เครื่องมือ (ไลบรารี MIT — ใช้เชิงพาณิชย์ได้ ไม่ต้องเขียน almanac เอง)
- **lunar-python (6tail)** — ติดตั้งแล้วในโปรเจกต์ ✅ ให้ครบทุกช่องข้างบน (ตรวจรันจริง 16 ก.ค. 2026: 辛卯日 / ผู้คุมวัน 成 / 天德 หวงเต้า吉 / ชงไก่ / ทิศเงิน正东 / 宜嫁娶祭祀... / 忌掘井伐木...)
- cnlunar (สำรอง, อิงตำราหลวงชิง) · mmcal (ฝั่งพม่า, พอร์ตแล้วบางส่วน)

## 4) ✅ สิ่งที่ "ทำไปแล้ว" ด้วยศาสตร์จีน (LIVE บนเว็บ)
อยู่ใน **`horoscope.py`** (ฟีเจอร์ดวงรายสัปดาห์/รายเดือน) — ใช้ lunar-python จริง 3 สัญญาณ:
1. **การชงนักษัตร** (`getDayChongShengXiao`) → วันไหนชงปีเกิดลูกค้า ตัด −3 คะแนน
2. **หวงเต้า/เฮยเต้า** (`getDayTianShenLuck`) → 吉 +1 / 凶 −1
3. **ผู้คุมวัน** (`getZhiXing`) → วัน 成/開 +1 / วัน 破 −1

→ รวมกับสัญญาณพม่า (ยัตยาซา/เปียตะดา/ดาววันเกิด/โกนะวิน) เป็นคะแนนดวงรายวัน + ปีนักษัตรจีนโชว์ในผล + เลขนำโชคผสมอินเดีย **ครบ 3 ภาษา ขึ้นเว็บ ft.jbacworkhub.com แล้ว**

## 5) 🔜 สิ่งที่ "ทำต่อได้ทันที" (ความรู้พร้อม เครื่องมือพร้อม แค่ยังไม่ประกอบ)
| ฟีเจอร์ | ใช้อะไรที่มีอยู่แล้ว | สถานะ |
|---|---|---|
| **หาฤกษ์กิจการ** (เปิดร้าน/เซ็นสัญญา/ย้ายบ้าน/แต่งงาน) | 宜/忌 (`getDayYi/getDayJi`) — **ยังไม่ได้ดึงมาใช้เลย** + ชง + officer | สถาปัตยกรรมร่างไว้แล้วใน auspicious-timing-cn-mm.md |
| **ทิศรับทรัพย์รายวัน** | 財神 (`getDayPositionCaiDesc`) | ยังไม่ใช้ |
| **เปิดร้านกี่โมงดี** | ฤกษ์รายชั่วโมง 時辰 | ยังไม่ใช้ |
| **ดวงจีนเต็ม (ปาจื่อ 八字)** | กานจือ 4 เสา + ธาตุ 五行 | ยังไม่ใช้ (ต่อยอดเป็น "ดวงตามศาสตร์จีน" ที่พี่อยากได้) |

## 6) ⚠️ ข้อควรระวัง (จากผลตรวจสอบ)
- **อย่า hard-code ตาราง officer→กิจกรรมเอง** (แต่ละสำนักไม่ตรง) → ใช้ 宜/忌 จากไลบรารีเป็นแหล่งเดียว
- 宜/忌 ไม่มีมาตรฐานกลาง → ยึด 6tail สายเดียว บอกผู้ใช้ว่าอิงสายนี้
- วันร้ายพิเศษ 三娘煞/四離四絕 สูตรยังไม่ผ่านตรวจ — อย่าใส่จนกว่าจะ verify

## 7) ❓ ยังต้องวิจัยต่อ (Open Questions)
1. **น้ำหนักคะแนนจีน:พม่า** — คนจีนพม่าจริงเชื่อศาสตร์ไหนมากกว่าเมื่อขัดกัน? (ย่างกุ้ง/มัณฑะเลย์ใช้ทงสิ่งฮ่องกงไหม)
2. เทียบ 宜/忌 ของ 6tail vs cnlunar vs ทงสิ่งฉบับพิมพ์ หลายวัน → เลือกสายมาตรฐาน
3. verify 三娘煞 / 四離四絕
4. คำแปลกิจกรรม 宜/忌 (嫁娶/開市/入宅...) เป็นไทย/พม่า/อังกฤษ ให้ครบ (ตอนนี้เป็นจีนดิบ)
