## กลไกจีนที่ยืนยันแล้ว (confidence สูง)

1. **กานจือ (干支)** — วัฏจักร 60 วันคำนวณจากวันที่แบบ deterministic (ไลบรารีทำให้)
2. **12 ผู้คุมวัน (建除十二神)** — สูตร: officer = (branch วัน − branch เดือน 月建) mod 12 เรียง 建除滿平定執破危成收開閉
   ⚠️ กับดัก 2 จุด: (a) "เดือน" = เดือนสุริยคติตามปักข์ (เริ่ม 立春 ฯลฯ) **ไม่ใช่เดือนจันทรคติ** (b) ทุกครั้งข้าม 交節 officer ซ้ำหนึ่งวัน — 6tail จัดการให้แล้ว
3. **การชง (沖)** — วัน branch ชนกับปีนักษัตรผู้ใช้ = ห้ามใช้วันนั้น → ได้ฟีเจอร์เฉพาะบุคคล (เหมือนวันเกิด 8 วันพม่าของเรา)
4. **Use case ตรง:** ทงสิ่งใช้เลือกวัน เปิดกิจการ/เซ็นสัญญา/ย้ายบ้าน/แต่งงาน จริงในวัฒนธรรมจีน — format 宜/忌 รายวันคือสิ่งที่ลูกค้าจีนคุ้นเคย

## ⚠️ สิ่งที่ห้ามทำ (ผลจากการตรวจสอบ)
- **อย่า hard-code ตาราง "officer→กิจกรรม" เอง** — ตารางที่เจอในเว็บถูกหักล้าง (แต่ละสำนักไม่ตรงกัน) → ใช้ 宜/忌 สำเร็จรูปจากไลบรารีเป็น source of truth เดียว และบอกผู้ใช้ว่าอิงสายไหน
- 宜/忌 ไม่มีมาตรฐานกลาง — เลือกไลบรารีเดียว (แนะนำ 6tail เพราะตรง almanac พาณิชย์ที่คนใช้จริง) อย่าผสม
- วันร้ายพิเศษ (三娘煞, 四離四絕) สูตรที่เจอยังไม่ผ่านตรวจ — อย่าใส่จนกว่าจะ verify (楊公忌 มีใน 6tail API แล้ว)

## สถาปัตยกรรมฟีเจอร์ (พร้อมสร้าง)
```
input: กิจกรรม + วันเกิด/ปีนักษัตร + ช่วงวันที่ (เช่น 30 วันข้างหน้า)
สำหรับแต่ละวัน:
  จีน:   lunar-python → 宜/忌 (กิจกรรมอยู่ใน 忌? ตัด) + ชงนักษัตรผู้ใช้? (ตัดทิ้ง)
         + 破日/เฮยเต้า (ลบ) + หวงเต้า/宜 (บวก) → คะแนนจีน
  พม่า:  mmcal.py → เปียตะดา/Yatyotema/Mahayatkyan (ลบ/ตัด) + ยัตยาซา (บวก)
         + วันเกิดผู้ใช้ 8 วัน (ระบบเดิม) → คะแนนพม่า
  รวม:   คะแนนสองศาสตร์ (น้ำหนัก = product decision — รอวิจัยพฤติกรรมคนจีนพม่า)
output: จัดอันดับวันดีสุด + เหตุผลรายวัน + ชั่วโมงมงคล (時辰 จาก 6tail)
```

## ❓ Open Questions (คิวรอบต่อไป)
1. **ความหมายเชิงธรรมเนียมของวันพม่า** (Thamanyo ห้ามอะไร, Nagapor เหมาะอะไร ฯลฯ) — รอบนี้ได้แค่ "วิธีคำนวณ" ยังไม่ได้ "ความหมายเชิงกิจกรรม" ที่ผ่านการตรวจ → ต้องหาแหล่งพม่าปฐมภูมิ (ตำราโหรพม่า/ปฏิทินพระ/ค้นภาษาพม่า)
2. **Nagahle (ทิศหัวนาค) กับการย้ายบ้าน/เดินทาง + เดือนห้ามแต่งงาน (เข้าพรรษา?) + พิธีบูชานัตเปิดร้าน** — ไม่มี claim รอดตรวจ
3. **พฤติกรรมคนจีนพม่าจริง** (ย่างกุ้ง/มัณฑะเลย์ ใช้ทงสิ่งฮ่องกง? ศาสตร์ไหนชนะเมื่อขัดกัน?) — จำเป็นต่อการตั้งน้ำหนักคะแนน
4. **เทียบ 宜/忌 ระหว่าง 6tail vs cnlunar vs ทงสิ่งฉบับพิมพ์** หลายๆ วัน เพื่อเลือกสายมาตรฐานของเรา
5. **สูตร 三娘煞 / 四離四絕** — verify ก่อนใช้
